### 1. Описание
Проект предназначен для автоматизации функционального и регрессионного тестирования веб-приложения SauceDemo, 
которое используется для демонстрации возможностей платформы Sauce Labs и обучения автоматизации тестирования.

| Компонент             | Технология       | Назначение         |
|-----------------------|------------------|--------------------|
| Язык программирования |Java |Разработка автотестов|
| Фреймворк тестирования |TestNG|Организация и запуск тестов|
| Инструмент автоматизации |Selenium WebDriver | Взаимодействие с браузером|
 Управление зависимостями |Maven|Сборка и управление библиотеками|

### 2. Подготовка окружения
* Установить JDK (рекомендуется версия 17+).
* Настроить Maven для управления зависимостями.
* Добавить зависимости Selenium WebDriver, TestNG.
* Настроить драйвер браузера.
* Создать структуру проекта: src/main/java, src/test/java, resources.

### 3. Структура проекта
```
SauceDemo/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── pages/        # Page Object классы
│   │   │   └── utils/         # Вспомогательные утилиты
│   │   └── resources/        # Конфигурационные файлы, логи
│   └── test/
│       ├── java/
│       │   └── tests/         # Тестовые классы (TestNG)
│       └── resources/        # TestNG XML, properties
├── target
├── pom.xml
└── README.md
```
### 4. Основные сценарии для автоматизации
#### Авторизация  
   * Вход с валидными данными.  
   * Вход с невалидным логином.  
   * Вход с невалидным паролем.  
   * Вход с пустыми полями.
#### Работа с каталогом товаров  
   * Проверка отображения всех товаров на главной странице.  
   * Проверка наличия названия, цены, описания и кнопки "Add to cart" у каждого товара.  
   * Фильтрация товаров по названию.  
   * Сортировка товаров (по возрастанию/убыванию цены).  
#### Корзина (Cart)  
   * Добавление одного товара в корзину.  
   * Добавление нескольких товаров в корзину.  
   * Удаление товара из корзины.
#### Оформление заказа (Checkout)
   * Заполнение информации о пользователе (имя, фамилия, почтовый индекс).  
   * Проверка валидации полей (например, обязательность индекса).  
   * Переход к подтверждению заказа.  
   * Завершение оформления и возврат на главную страницу. 
### 5. Рекомендации по реализации
   * Использовать паттерн Page Object для каждой страницы.
   * Выносить тестовые данные в отдельные файлы (например, .properties или JSON).
   * Применять аннотации TestNG (@BeforeMethod, @AfterMethod).
### 6. Запуск тестов
```
   mvn clean test        # Для Maven
```
